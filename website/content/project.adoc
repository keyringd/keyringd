:notitle:

Keyringd is an open-source SSH agent that combines hardware-protected keys with passkey-based authorization. It was started by a maintainer of WebAuthn4J, an open-source server-side WebAuthn library, to explore how passkeys could be used beyond website sign-ins.

The goal was to protect SSH private keys in hardware—not at the cost of convenience.

== Project principles

We prioritize security and transparency. We keep dependencies to a minimum and work toward reproducible builds, so that published binaries can be independently verified against the source.
