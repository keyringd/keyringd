HARDWARE-BACKED SSH KEYS, CERTIFIED BY A PASSKEY.

Protect your SSH keysfrom theft.

Not at the cost of convenience.

Keyringd is an open-source SSH agent that uses a hardware-backed device key for everyday SSH. Each computer gets its own device key, certified during setup by your passkey acting as the SSH CA.

No CA server. No identity provider. No cloud service required.

Add the CA public key to authorized_keys once. The same entry continues to work even when you replace your computer. After setup, keep using SSH as usual—your device key handles each connection locally.

BEYOND PRIVATE KEY FILES

Keys stay in hardware.
Only signatures leave.

SSH private keys are typically stored as files. If your computer is compromised, those files can be stolen and used elsewhere.

Keyringd keeps each computer's private key in its TPM or Secure Enclave. The hardware signs your connections without letting the private key leave.

DEVICE CHANGES, SIMPLIFIED BY SSH CERTIFICATES

New computer.
Same server setup.

A hardware-backed private key cannot move to your next computer. Normally, replacing the computer means creating a new key and registering it on every server that trusted the old one.

With Keyringd, your servers trust your passkey’s CA public key instead. Your passkey certifies each computer’s device key, so replacing your computer requires no changes to your server configuration.

Use your passkey when setting up a computer. Everyday SSH connections use its device key—no passkey authentication, no security key to carry.
